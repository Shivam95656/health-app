  1. Go to render.com
  2. Sign up with GitHub account
  3. Click "New" → "Web Service"
  4. Connect your GitHub repo (Shivam95656/health-app)
  5. Fill form:
     - Name: health-app
     - Build command: npm install
     - Start command: npm start
  6. Add Environment Variables:
     - SUPABASE_URL
     - SUPABASE_KEY
     - GEMINI_API_KEY
  7. Click Deploy
  
  For ML Service (separate):
  8. Click "New" → "Web Service" again
  9. Same repo, different config:
     - Build command: pip install -r ml_service/requirements.txt
     - Start command: cd ml_service && python predict_service.py
  10. Update server.js with Render.com ML service URL


OPTION C: HEROKU (EASY - PAID)
  
  1. Download Heroku CLI from heroku.com/download
  2. Open terminal and run:
     heroku login

     heroku create your-app-name
     heroku config:set SUPABASE_URL=your_url
     heroku config:set GEMINI_API_KEY=your_key
     git push heroku main
  4. View app: heroku open

================================================================================
                    STEP 9: TROUBLESHOOTING
================================================================================

"Port 3000 already in use"
  → Find: netstat -ano | findstr :3000
  → Kill: taskkill /PID [NUMBER] /F
  → Or use: PORT=3001 npm start

"Git push rejected - Repository not found"
  → Check: git remote -v
  → Should show: origin https://github.com/Shivam95656/health-app.git
  → Fix: git remote remove origin
         git remote add origin https://github.com/Shivam95656/health-app.git

"Cannot connect to ML service"
  → Check if running: python predict_service.py working?
  → Check firewall allows port 5001
  → Check ML_SERVICE_URL in server.js

"npm start fails with module not found"
  → Run: npm install
  → Check: package.json exists in folder

"Python predict_service.py fails"
  → Install requirements: pip install -r ml_service/requirements.txt
  → Check Python version: python --version (needs 3.7+)
